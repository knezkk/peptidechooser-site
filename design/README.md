# Design source

`tokens.json` and `bundle.css` are copies of the Master 1 design book (https://claude.ai/artifact/Q3fubteJey9MYFjYQzGGNr). Do not edit them here: change the book, then copy. `build.py` compiles `tokens.json` into `dist/assets/tokens.css`; `assets/site.css` holds only layout that uses those variables.
