# Pages and buttons

What goes on each page type, top to bottom, and which button sits where. A page is built only from the parts listed for its type. A new part is added to this book first.

One file per page type (split 5 Nov 2026). An older note saying "pages.md, <section>" means that section in one of these:

- [every-page.md](pages/every-page.md): Every page (header, footer, cookie notice, header search, jump row), Page anatomy, Schema.org, Rules that apply to every page, 404
- [home.md](pages/home.md): Home `/`, the two steps, the goal list, Creators
- [goal.md](pages/goal.md): Category, the goal pages `/hair/`, `/weight-loss/` and the rest
- [seller.md](pages/seller.md): Seller `/sellers/<slug>/`, Vendor
- [peptide.md](pages/peptide.md): Peptide, Peptides `/peptides/`
- [compare.md](pages/compare.md): Compare, Compare any two, Compare pairs
- [sellers-list.md](pages/sellers-list.md): Sellers `/sellers/`
- [letters.md](pages/letters.md): Letters `/fda-warning-letters/`
- [learn.md](pages/learn.md): Learn `/learn/`, Guide `/learn/<topic>/`
- [trust.md](pages/trust.md): Trust pages, Sources `/sources/`, Paid link redirect page `/out/<slug>/`
- [search.md](pages/search.md): Search `/search/`
- [windows.md](pages/windows.md): Seller window, Clinic window
- [parts.md](pages/parts.md): Buttons, Option rows, Pictures, Seller tile, Product drawings, Goal drawings, Goal photos, Logo, Medical cues (figure, chips, price pad)
