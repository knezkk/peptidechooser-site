# Pages and buttons

What goes on each page type, top to bottom, and which button sits where. A page is built only from the parts listed for its type. A new part is added to this book first.

New page types from the site map (`docs/site-map-rules-2026-11-08.md`, owner 8 Nov 2026): brand `/peptides/<substance>/<brand>/`, seller offer `/sellers/<seller>/<substance>/`, lab `/labs/<lab>/`, company FDA letters `/fda-warning-letters/<company>/` and tool `/tools/<tool>/` have their templates in new-types.md (waits for ODOBRENO DIZAJN, task 3A). None is built before that approval.
