# Share-image fonts

The fonts `tools/og.py` draws share images with, kept in the repo so the deploy needs no network font service and no apt font packages (owner, 11 Nov 2026). Latin and Latin Extended subsets, from Google Fonts, 11 Nov 2026.

- Bricolage Grotesque 800 (titles): Copyright 2022 The Bricolage Grotesque Project Authors.
- Public Sans 800 (the name in the logo line): Copyright 2015 The Public Sans Project Authors.
- Atkinson Hyperlegible 400 and 700 (kind line and tagline): Copyright 2020 Braille Institute of America, Inc.

All three are under the SIL Open Font License 1.1; its text is in `assets/fonts/OFL.txt`.
